CClear 3.0 的正式界面有七个模块。页面切换不会丢掉已经扫到的结果。磁盘分析、垃圾扫描、重复文件和智能扫描共用一个任务：同一时间只跑一个重型扫描，可以从任意页面看到进度并取消。取消后保留已经完成的部分结果。再启动另一个重型任务时，会说明当前正在执行什么，不会把正在跑的任务悄悄停掉。

## 总览

启动后进入总览，不直接打开磁盘分析。这里显示系统盘总容量、已用和剩余，以及最近扫描时间、垃圾候选空间、重复文件可释放空间、大文件摘要、已安装软件摘要和最近一次清理结果。

「开始智能扫描」只做只读分析，按五个阶段进行：垃圾候选项、磁盘占用、重复文件、软件信息、系统与开发环境。完成后给出统一摘要，由用户选择进入哪个模块处理。

## 垃圾清理

流程是扫描、摘要、审核、确认、执行、结果。审核按推荐、谨慎、高级系统项目分组，并显示数量、预计容量、风险和是否需要管理员权限。扫描错误、截断和读取失败会留在结果里。

高风险项目默认关闭。管理员项目会标明。确认使用应用内对话框，需要输入「确认清理」。结果报告释放空间、删除、跳过、失败和日志位置。中途取消记为部分完成。

默认可以处理的是临时文件、缩略图、Internet 缓存和浏览器缓存。普通临时文件只删除超过 72 小时未修改的内容。浏览器只删除缓存；浏览器正在运行时会跳过。文档、桌面、下载、照片、音乐、OneDrive、Program Files、System32 和 WinSxS 不在直接删除范围内。旧版 Windows 交给 Windows 磁盘清理，组件存储先分析再清理。

## 磁盘分析

磁盘分析只读。气泡图是页面主体，目录列表和气泡同时可见。悬停列表会标出对应气泡，悬停气泡也会标出对应目录。单击气泡进入该目录，面包屑可以返回。

同一套颜色也用于矩形树图。另外可以按文件类型查看，或列出大文件。定位大文件只会打开资源管理器。

## 重复文件

扫描前先选择磁盘或目录，也可以排除目录。常用位置有下载、图片、视频和文档。扫描分枚举、候选筛选和内容哈希，并显示权限错误和截断。

一组里标记为「默认保留」的是扫描时遇到的第一份，不是单独的推荐算法。一组至少保留一份。系统目录、VHD、VHDX 和受保护文件不能删除。副本只能移入回收站，确认语是「移到回收站」，不能从这里永久删除。结果可以按可释放空间排序，重复组可以展开或折叠。

## 软件管理

可以按名称搜索，按名称或容量排序，并按发布者筛选。列表显示版本、发布者、位置和登记容量，并区分 Win32、Microsoft Store 和系统组件。拿不到应用图标时使用统一的首字占位。

系统组件不提供卸载。卸载前会说明 CClear 只启动系统登记的卸载程序，确认语是「启动卸载」。CClear 不删除软件安装目录。卸载程序退出后可以手动刷新列表。

## 系统占用

这一页只读，不删除系统文件。占用按 Windows 系统文件、虚拟内存和休眠文件、Docker、WSL、开发工具缓存、其他开发环境分组。每一项可以查看位置和说明。有对应入口的项目可以打开 Windows 设置。

## 清理历史

清理记录按时间列出，同时显示逻辑空间和估算空间。

## 安装与卸载

安装包依次经过欢迎、许可说明、安装位置、安装进度和完成。完成后在开始菜单、桌面和「应用和功能」中留下入口。卸载使用安装目录中的 `Uninstall.exe`。安装中途失败会撤销本次写入的程序文件。
