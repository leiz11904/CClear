# CClear

CClear 是 Windows 系统盘清理与空间管理工具。垃圾清理扫描临时文件、缓存和回收站，在你确认后删除。磁盘分析、重复文件、软件和系统占用是只读功能，不会把用户文件当成垃圾。

当前安装包在 `dist/CClear-Setup-2.7.0.exe`。2.1–2.6 安装包仍保留在 `dist/`，用于分版本验收。双击后会依次出现欢迎、许可说明、安装位置、安装进度和完成页，并在开始菜单、桌面和“应用和功能”里留下入口。卸载使用安装目录中的 `Uninstall.exe`。

2.7.0 把侧栏、底部操作和勾选改成系统按钮/复选框，避免自绘被盖住后出现空白按钮和乱字符。清理卡片收紧，扫描时间和待分析状态分开显示。可执行文件默认没有 Authenticode 签名，本程序不会伪造签名。清理引擎和安全白名单没有放宽。还没有在真实 Windows 上跑过 NTFS 联接、占用和权限测试，不能视为已经完成生产安全验证。

## 会清理什么

默认勾选的是临时文件、缩略图、Internet 缓存和浏览器缓存。普通临时文件只删除超过 72 小时未修改的内容，文件年龄本身不能让其他目录进入清理范围。浏览器只删除缓存；浏览器正在运行时会跳过，不会结束浏览器。错误报告和回收站单独列出，默认不勾选。

显卡着色器缓存、崩溃转储、Windows 更新日志、开发工具缓存、传递优化缓存、旧版 Windows、Windows 更新下载缓存和组件存储清理默认不勾选，并放在“高级清理”中。旧版 Windows 只交给 Windows 磁盘清理，组件存储会先分析再清理，不会直接删除 WinSxS。

清理前会列出将删除的项目；高级清理项还会再确认一次。

## 不会清理什么

文档、桌面、下载、照片、音乐、OneDrive、Program Files、System32 和 WinSxS 都不在清理范围内。删除前会核对文件的真实路径，并跳过快捷方式、目录联接点和正在使用的文件。大文件和重复文件不会自动进入垃圾清理。WSL 虚拟磁盘禁止直接删除。

## 重新编译

安装 Go 后运行：

```sh
sh scripts/build-windows.sh
```

脚本会交叉编译清理程序和安装向导，并把清理程序附在安装包末尾。在 Windows 上双击 `dist/CClear-Setup-2.7.0.exe` 即可安装。静默安装使用 `CClear-Setup-2.7.0.exe /S`。

生成的程序没有代码签名。Windows 首次打开安装包时，SmartScreen 可能提示“Windows 已保护你的电脑”。选择“更多信息”，再选择“仍要运行”。不要从程序内部绕过 SmartScreen。若你有自己的 Authenticode 证书，可设置 `CCLEAR_CERT` 后运行 `sh scripts/sign-windows.sh`。
