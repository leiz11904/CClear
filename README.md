# CClear

CClear 3.0 是 Windows 系统空间管理工具。正式安装包使用 Modern 界面，包含垃圾清理、磁盘分析、重复文件、软件管理、系统占用、开发环境占用和清理历史。所有删除操作都必须先扫描并由用户确认；磁盘分析和系统占用页面保持只读。

安装包不在仓库里。`dist/` 已被 git 忽略，克隆仓库后不会带有 `CClear-Setup-3.0.0.exe`。本地构建会把程序写到 `dist/`。对外分发使用 GitHub Releases：把本地或 GitHub Actions 产物里的安装包和 `SHA256SUMS.txt` 附到对应版本的 Release。Actions 只构建并上传产物，不会自动发布 Release。

双击安装包后会依次出现欢迎、许可说明、安装位置、安装进度和完成页，并在开始菜单、桌面和“应用和功能”里留下入口。卸载使用安装目录中的 `Uninstall.exe`。安装中途失败会撤销本次写入的程序文件，不会留下半份安装，也不会删除安装目录里的其他文件。

3.0.0 的正式安装包切换到 Modern 界面。清理模块继续复用原有安全白名单与 Windows 官方清理接口；重复文件只能逐个移入回收站且必须至少保留一个副本；软件管理只启动系统登记的卸载器。磁盘分析提供排行、空间气泡、矩形树图、文件类型和大文件视图。日志超过上限时删除最旧的文件，至少保留最新一份。可执行文件默认没有 Authenticode 签名，本程序不会伪造签名。

## 会清理什么

默认勾选的是临时文件、缩略图、Internet 缓存和浏览器缓存。普通临时文件只删除超过 72 小时未修改的内容，文件年龄本身不能让其他目录进入清理范围。浏览器只删除缓存；浏览器正在运行时会跳过，不会结束浏览器。错误报告和回收站单独列出，默认不勾选。

显卡着色器缓存、崩溃转储、Windows 更新日志、开发工具缓存、传递优化缓存、旧版 Windows、Windows 更新下载缓存和组件存储清理默认不勾选，并放在“高级清理”中。这些项目默认关闭，需手动确认。旧版 Windows 只交给 Windows 磁盘清理，组件存储会先分析再清理，不会直接删除 WinSxS。

清理前会列出将删除的项目；高级清理项还会再确认一次。

## 不会清理什么

文档、桌面、下载、照片、音乐、OneDrive、Program Files、System32 和 WinSxS 都不在清理范围内。删除前会核对文件的真实路径，并跳过快捷方式、目录联接点和正在使用的文件。大文件和重复文件不会自动进入垃圾清理。WSL 虚拟磁盘禁止直接删除。

## 重新编译

安装 Go 1.23.1 后运行：

```sh
sh scripts/build-windows.sh
```

脚本会先构建 React 前端，再编译 Wails Modern 主程序和安装向导，并把 Modern 主程序附在安装包末尾。输出在本地的 `dist/cclear.exe` 和 `dist/CClear-Setup-3.0.0.exe`，这两个文件不会进入 git。在 Windows 上双击本地生成的 `dist/CClear-Setup-3.0.0.exe` 即可安装。静默安装使用 `CClear-Setup-3.0.0.exe /S`。

生成的程序没有代码签名。Windows 首次打开安装包时，SmartScreen 可能提示“Windows 已保护你的电脑”。选择“更多信息”，再选择“仍要运行”。不要从程序内部绕过 SmartScreen。若你有自己的 Authenticode 证书，可设置 `CCLEAR_CERT` 后运行 `sh scripts/sign-windows.sh`。没有证书时脚本不会签名。
